# 🎁 ScanConcours
**L’assistant intelligent pour vos jeux concours**  
Scraping, favoris, suivi automatique des gains (à venir)

---

## 🚀 Présentation
ScanConcours est un outil conçu pour :

- récupérer automatiquement les jeux concours disponibles en ligne  
- permettre aux utilisateurs d’y participer facilement  
- suivre leurs participations et gains  
- détecter automatiquement les emails annonçant un gain (fonction "Mes gains")

Ce repository contient la version **frontend** du projet :  
HTML / CSS / JavaScript, moderne, responsive et extensible.
